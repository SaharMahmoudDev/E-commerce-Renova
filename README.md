# Renova E-commerce

A responsive, mobile-first online store built with vanilla JavaScript: multiple product categories, product details, search, cart, favorites, and sign-in.

**Live demo:** https://renova-store.pages.dev/

## Features
- Product categories (fashion, electronics, books, beauty, and more)
- Product details page
- Product search and filtering
- Dynamic cart and favorites saved in localStorage
- Sign in and register through a REST API
- Arabic and English support
- Responsive, mobile-first layout

## Tech Stack
HTML5 · CSS3 · JavaScript (ES6+) · Fetch API · REST API · localStorage

## Project Structure
```
├── index.html
├── html/   # category, product, cart, favorites, search, sign-in pages
├── css/
└── js/
```

## Getting Started
Open `index.html` in your browser, or serve the folder with any static server.

## What I Learned
- Building a multi-page store without frameworks
- Calling REST APIs with async/await
- Keeping cart and favorites state in localStorage
